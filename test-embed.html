Video Chapter Player Embed Test

This page demonstrates how to embed the Video Chapter Player using embed.js.

The player below is initialized from data in the data-config attribute.

How it works:

  1. Create a div with class "video-chapter-player"
  2. Add a data-config attribute with your player configuration as JSON (with single quotes)
  3. Include the embed.js script which will automatically:
    • Load chapterplayer.css and chapterplayer.js
    • Initialize the ChapterPlayer with your configuration
    • Convert single-quoted JSON to standard double-quoted JSON for parsing

Configuration Options:

  • videoUrl: The URL of the MP4 video to play
  • posterUrl: The URL of an image to display before the video plays
  • useExternalCss: Set to true to use a link element for CSS instead of fetching inline. This makes it easier to test CSS changes during development.
